# agents

this file defines the agents available in the c-beam workspace.

## general agent

the default agent for general coding tasks, refactoring, and development work.

## django agent

specialized agent for django-specific tasks, including models, views, templates, and django rest framework.

## testing agent

agent focused on testing, test generation, and quality assurance.

## documentation agent

agent for generating and maintaining documentation, including api docs and code comments.

## security agent

agent specialized in security analysis, vulnerability assessment, and secure coding practices.
